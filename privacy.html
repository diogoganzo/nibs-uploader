Nibs Uploader — Privacy Policy

Last updated: November 10, 2026

Nibs Uploader is a private tool operated by the creator of the "Gem Goblin" channels (contact: nibsgemgoblin@gmail.com). It is used only by its owner to upload original short videos to the owner's own social media accounts (TikTok, YouTube). It is not offered to the public.

What we access

  • When the owner connects an account, the platform (e.g. TikTok) provides an access token and basic account information (display name, avatar, open ID) so the tool can confirm which account is connected.
  • The tool uploads video files and captions that the owner created and chose to publish.

YouTube API Services

Nibs Uploader uses the YouTube API Services (YouTube Data API v3) to upload the owner's own videos to the owner's own YouTube channels. By using Nibs Uploader you agree to be bound by the YouTube Terms of Service. Information obtained through the YouTube API Services is also handled in accordance with the Google Privacy Policy.

  • YouTube data accessed: the authorized channel's ID and title (channels.list, mine=true), used only to confirm which channel is connected; and the video file, title, description, tags and privacy settings that the owner chooses to upload (videos.insert).
  • Scopes: youtube.upload and youtube.readonly. No other YouTube data is requested.
  • Storage: the OAuth access/refresh tokens are stored only on the owner's computer (file permissions 600). Channel information is not stored; it is only displayed in the terminal.
  • Sharing: YouTube API data is never shared with, sold or transferred to any third party.
  • Revoking access: access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • Deletion: deleting the local token file immediately removes all stored YouTube API data. Any stored data is deleted within 7 days after access is revoked, and no YouTube API data is kept for more than 30 days without being refreshed.

What we store

  • Only the access/refresh tokens of the owner's own account, stored locally on the owner's computer with restricted file permissions. No other user data is collected, stored, sold or shared.

What we do not do

  • We do not access other users' accounts, content, followers or messages.
  • We do not use analytics, cookies, advertising or tracking.
  • We do not share any data with third parties.

Deleting data

The owner can revoke access at any time in the TikTok/YouTube app settings ("Manage app permissions"); deleting the local token file removes all stored data.
